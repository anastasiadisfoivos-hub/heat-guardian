# B6b — 09_guardian report (Nov 12)

**Status:** the code compiles and passes the host tests. It has never been run on a board, and the 72 h soak is planned but has not been run.

## Deliverables
- `fw/09_guardian/09_guardian.ino` is generated by `fw/tools/make_09.py`. It is 08_logger v1.1.1 with the 08 sections unchanged, plus `guardian_layer.inc` (Guardian Loop, 07 screens and haptics, BLE service, Body Twin, POF).
- `fw/09_guardian/frozen/` holds 29 files copied from tag `hg2-freeze-2` by `fw/tools/sync_frozen.sh`. All 29 are byte-identical to the tag (sha256 in `FROZEN_SHA256.txt`), the FROZEN.txt hashes match, and the weights CRC is 0xB32FA3CA. They are compiled through the `fz_*.c` wrappers, which add `fw_flags.h` pragmas (single-precision constants, fp-contract off). On the core's arm gcc the pragma build matches the flag build.
- `hg_fw.c/.h` is the glue: minute summaries, guardian step, twin ingest and nightly save, PPG duty, records, and a 24 h STATUS ring.
- QSPI log: one daily file `/log/sNNNN.bin` with 2 records per minute (inputs + guardian record, marker 13), flushed every 10 min. `parse_log.py --guardian-out` reads it.
- BLE: custom service `0c760000-…` (STATUS/CMD/INFO). The frames follow `hg_frames.h` and `ble_vectors.json`. `dashboard.html` + `hg_ble.js` give a Chrome Web Bluetooth dashboard.
- Docs: `README.md` (flash guide), `SOAK_PLAN.md` (72 h), `BOOT_LOG.txt` (expected boot output).

## Deviations and open items
1. **Flash is 36 %, over the 30 % budget.** I have not applied the R4 levers: dropping USB serial saves about 19 KB but removes the console needed for the soak, and a minimal ST7789 driver saves about 20 KB. The manager needs to decide.
2. The PPG runs for the first 30 s of every minute, not 30 s every 2 min. The reason is that frozen hr_valid needs OK in 3 of the last 5 minutes.
3. The core swallows POFWARN, so the firmware polls VBAT instead (< 3.40 V → flush, motor off).
4. "I'm OK" is shown on screen at once. The guardian confirms it at the next minute, so up to 60 s later.
5. Wrist-raise wake is not implemented (the button wakes the screen).
6. The `guardian/c` working tree has moved on from the tag (M13 work by another builder). 09 is built from the tag only.

## Update B6-fastmath (T6b NO-GO): 08 v1.1.2, 09 v0.9.2
- **B1 fast-math.** `hg_nofastmath.h` (`#pragma GCC optimize ("no-fast-math")` plus a `used` isnan probe) is now the first include of every sketch file in both sketches. 09's `fw_flags.h` includes it first, so the frozen files get it through `fz_*.c` without being edited. `fw/tools/check_nofastmath.sh` checks three things: every source starts with it; a control `-Ofast` compile folds isnan to `movs r0,#0` while the header keeps a `vcmp`; and every object produced (08: 4/4, 09: 17/17) keeps the `vcmp`.
